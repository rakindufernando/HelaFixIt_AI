About the system

A clear way to connect residents with maintenance teams.

Apartment maintenance requests can be missed when they are handled through phone calls, messages, or paper records. This system keeps requests in one place so the building team can respond in an organized way.

Residents can submit issues, apartment admins can manage the ticket queue, technicians can update work progress, and system admins can manage users and settings.

01

Residents submit requests using a simple form.

02

Admins organize tickets and assign repair work.

03

Technicians update progress until completion.

Main features

Core functions for apartment maintenance handling

The landing page shows only public information. Private tickets, dashboards, and system records are available after login.

01

Online request form

Residents can submit faults with issue details, building block, floor, area, and description.

02

Ticket tracking

Users can view request status such as submitted, reviewed, assigned, in progress, and completed.

03

Admin ticket queue

Apartment admins can view active requests and organize work based on status and urgency.

04

Technician assignment

Repair jobs can be assigned to suitable technicians according to the type of maintenance issue.

05

Repair progress updates

Technicians can update work progress, add repair notes, and close completed jobs.

06

Reports and summaries

Management users can view summaries about ticket counts, common issue types, and workload.

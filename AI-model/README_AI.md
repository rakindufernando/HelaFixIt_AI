# Local AI module

The AI module uses locally stored scikit-learn models. The application does not require an external AI prediction API for its core ticket decisions.

## Data

- `Data/maintenance_tickets.csv` contains 60,000 labelled multilingual maintenance tickets.
- `Data/challenge_test.csv` contains additional challenge cases.
- `Data/language_validation_cases.csv` contains language recognition checks.
- `Data/validation_cases.csv` contains focused end to end AI decision cases.

The main dataset contains English, Sinhala, Singlish and Mixed language records.

## Training

- `Training/generate_dataset.py` creates the prepared labelled dataset.
- `Training/train_models.py` trains the TF-IDF based category and priority classifiers.
- `Training/evaluate_models.py` produces model evaluation outputs.
- `Training/test_model_examples.py` tests representative maintenance descriptions.
- `Training/validate_ai_cases.py` checks focused AI and safety decisions.
- `Training/validate_language_recognition.py` checks language recognition cases.

HelaFixIt AI Frontend

This folder contains the web frontend for the HelaFixIt AI apartment maintenance management system.

Frontend technologies
HTML5
CSS3
JavaScript

Main user interfaces
Resident portal
Apartment administrator portal
Technician portal
System administrator portal
Public authentication and account pages
Responsive landing page

System integration
The frontend communicates with the Flask backend through the application API.
Authentication and role-based access are handled by the backend.
Maintenance ticket information is stored in the MySQL database.
AI predictions are generated by the locally trained Python machine learning components.
The frontend displays predicted category, priority, risk information, safety information and technician recommendations returned by the backend.

Supported maintenance ticket languages
English
Sinhala
Singlish
Mixed-language text

Frontend structure
Assets contains images and other interface resources.
CSS contains shared and role-specific styling.
JS contains shared API logic and role-specific JavaScript.
Pages contains the public, resident, apartment administrator, technician and system administrator interfaces.

Security
No production credentials or API secrets are stored in the frontend source.
Authentication and authorization decisions are enforced by the backend.
Runtime user and ticket data should not be hardcoded into frontend files.

Responsive design
The interfaces are designed for desktop, tablet and mobile screen sizes.
